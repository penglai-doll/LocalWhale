# LocalWhale v0.1.5 — Frontend smoke gate accepts Harness 0.1.1 / 前端冒烟门适配 Harness 0.1.1

Release date / 发布日期：2026-09-02

LocalWhale 0.1.5 fixes the last version-fragile assertion in the Harness update pipeline so the official DeepSeek Harness `0.1.1-rc.2` can complete validation. The bundled initial runtime remains DeepSeek Harness `0.1.0-rc.6`, Node.js `24.18.1`, and pnpm `11.7.0`.

LocalWhale 0.1.5 修复了 Harness 更新管线中最后一个绑定旧版结构的断言，使官方 DeepSeek Harness `0.1.1-rc.2` 能够完整通过验证。随包初始运行时仍为 DeepSeek Harness `0.1.0-rc.6`、Node.js `24.18.1` 与 pnpm `11.7.0`。

## Fixed / 修复

- After the 0.1.4 allowlist fix, updating to Harness `0.1.1-rc.2` failed at the smoke stage with `Candidate Harness frontend did not expose a complete client boot manifest`. Harness ≤ 0.1.0 injects an inline `window.__DSH_BOOT__` manifest (referencing `@deepseek-ai/dsh-client-runtime`) into the served HTML; 0.1.1+ instead serves the Vite app shell (`<div id="root">` plus a module script) and fetches the boot manifest at runtime, so both hardcoded markers disappeared from the page.
- 0.1.4 修复白名单后，更新到 Harness `0.1.1-rc.2` 在冒烟阶段报 `Candidate Harness frontend did not expose a complete client boot manifest`。Harness ≤ 0.1.0 由宿主向页面注入内联 `window.__DSH_BOOT__` 清单（引用 `@deepseek-ai/dsh-client-runtime`）；0.1.1 起改为直接返回 Vite 应用外壳（`<div id="root">` + module 脚本），boot manifest 由客户端运行时获取，两个硬编码标记随之从页面消失。
- The staged-runtime smoke now accepts either generation: the legacy inline boot manifest or the 0.1.1 app shell. The WebView smoke likewise requires only that the `#root` container renders, which is the actual acceptance signal for both generations.
- 暂存运行时冒烟现在同时接受两代结构：旧版内联 boot manifest 或 0.1.1 的应用外壳。WebView 冒烟同样只要求 `#root` 容器完成渲染——这才是两代前端共同的验收信号。

## Upgrade safety / 升级安全

- Settings, staged updates, `%USERPROFILE%\.dsh`, and the official Harness WebUI remain untouched. The relaxed smoke still rejects any page that is neither a boot-manifest page nor an app shell (for example an error page).
- 设置、暂存更新、`%USERPROFILE%\.dsh` 与官方 Harness WebUI 均不受影响。放宽后的冒烟仍会拒绝既非 boot manifest 页也非应用外壳的页面（例如错误页）。

## Known limits / 已知限制

- Windows 11 x64 only; no Windows 10, ARM64, Store, or cross-platform package.
- 仅支持 Windows 11 x64；不提供 Windows 10、ARM64、Microsoft Store 或跨平台版本。
- The installer remains unsigned and can show an unknown-publisher warning.
- 安装器仍未签名，Windows 可能显示“未知发布者”警告。
