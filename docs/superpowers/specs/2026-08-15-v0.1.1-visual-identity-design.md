# LocalWhale v0.1.1 视觉标识与可选角色主题设计规格

- 日期：2026-08-15
- 状态：已通过交互式设计评审，待实施
- 目标版本：LocalWhale 0.1.1
- 基线版本：LocalWhale 0.1.0

## 1. 背景与目标

LocalWhale 0.1.0 已能把 DeepSeek Harness 作为本地 Windows 桌面应用运行，但仍存在明显的视觉标识缺口：EXE、任务栏和托盘没有统一的应用图标，标题栏左侧使用系统 Emoji，标题栏与菜单的层级和对齐也不够接近原生 Windows 11 应用。

v0.1.1 的目标是：

1. 建立简洁、可在 16 px 下识别的 LocalWhale 独立图标体系。
2. 用微软官方 WinUI `TitleBar`、`MenuFlyout`、`InfoBar` 等模式改善宿主外壳。
3. 默认保留克制的原主题，并提供用户主动选择的“鲸鱼娘”主题。
4. 将已批准的原创鲸鱼娘人设用于可选主题，但不把人物细节塞进应用图标。
5. 从 v0.1.0 升级时保留现有 LocalWhale 设置和 Harness 的 `~/.dsh` 数据。

## 2. 非目标与边界

- 不修改、Fork 或重新排版 DeepSeek Harness 官方 WebUI。
- 不向 WebView2 页面注入 CSS、JavaScript、字体或角色素材。
- 不把 DeepSeek 官方鲸鱼 Logo 或网络二创图片直接作为 LocalWhale 成品素材。
- 不在 v0.1.1 引入窗口内循环动画、视频背景或 Live2D。
- 不增加常驻主题进程、联网主题商店或第三方主题包加载。
- 不改变 v0.1.0 的 Harness 生命周期、更新与回滚协议。

## 3. 视觉方向

### 3.1 双层视觉体系

LocalWhale 使用两层相互独立的视觉表达：

- **产品标识层**：极简“鲸尾水滴 + 负形 L 水波”徽记，用于 EXE、窗口、标题栏、任务栏、托盘、安装器和卸载项。
- **角色主题层**：已批准的原创白/银发鲸鱼娘，用于可选主题的启动、恢复和关于界面。

这样既能在小尺寸下保持清晰，也能让角色人设在有足够空间的界面中完整出现。

### 3.2 原创与参考边界

人设只继承“友好的 AI 鲸鱼娘”这一宽泛文化母题，以及用户选定的白/银发、蓝白海洋服装、鲸尾配件与额饰气质。成品使用重新设计的五官、服装结构、配件和 LocalWhale 专属 L 形水波吊坠，不复刻参考图的具体构图、姿势、服装或品牌 Logo。

批准的人设母版：

- `design/brand/v0.1.1/localwhale-mascot-character-sheet.png`
- `design/brand/v0.1.1/localwhale-mascot-character-sheet.prompt.md`

## 4. 应用图标规范

### 4.1 图形

- 外形采用带适度圆角的深海蓝底板。
- 中央图形由冰青色鲸尾水滴和负形 L 水波组成。
- 不使用人物脸、头发、服饰、文字或 DeepSeek 官方鲸鱼轮廓。
- 所有尺寸使用同一扁平几何构图；不为大尺寸增加额外装饰。
- 图形安全区不小于画布宽高的 8%，避免任务栏和安装器缩放裁切。

### 4.2 颜色

- 深海蓝：主背景，目标值约 `#24366F`。
- 冰青：主图形，目标值约 `#BDEEFF`。
- 可使用单一较亮蓝色作为小面积辅助，但总颜色不超过三种。
- 不依赖透明细线、阴影或低对比渐变传递轮廓。

最终颜色可在导出前做一次浅色、深色任务栏对比校准，但不得改变简洁原则。

### 4.3 输出与接入

提交一个源矢量文件和已导出的构建资产：

- `src/LocalWhale.App/Assets/Brand/LocalWhaleMark.svg`
- `src/LocalWhale.App/Assets/LocalWhale.ico`，包含 16、20、24、32、48、64、128、256 px。
- `src/LocalWhale.App/Assets/Brand/LocalWhaleMark-16.png`
- `src/LocalWhale.App/Assets/Brand/LocalWhaleMark-24.png`
- `src/LocalWhale.App/Assets/Brand/LocalWhaleMark-32.png`

构建消费已提交的 ICO/PNG，不要求最终用户或普通贡献者安装图像工具。维护用导出脚本可以依赖仓库文档中声明的开发工具。

接入点：

- `LocalWhale.App.csproj` 的 `ApplicationIcon`。
- `AppWindow.SetIcon` 使用 ICO 的绝对路径。
- 原生托盘从 LocalWhale 自身 EXE/ICO 提取 `HICON`，不再使用系统通用 Application 图标。
- Inno Setup 的 `SetupIconFile` 与 `UninstallDisplayIcon`。
- WinUI `TitleBar.IconSource` 使用 16/24 px 品牌图。

## 5. 主题模型

### 5.1 持久类型

新增：

```csharp
public enum VisualTheme
{
    Original,
    WhaleGirl
}
```

`AppSettings` 增加 `VisualTheme VisualTheme`。缺失、空值或未知值均安全回退到 `Original`。

### 5.2 默认与切换行为

- 新安装默认 `Original`。
- 从 v0.1.0 升级时，因为旧 JSON 缺少该字段，所以默认 `Original`。
- 用户可以在“…”菜单的“外观主题”子菜单中选择“原主题”或“鲸鱼娘”。
- 切换立即应用到宿主外壳并原子保存，不要求重启 Harness。
- 两种主题都继续跟随 Windows 的浅色/深色模式；角色主题不是强制浅色主题。
- 主题选择不改变 WebView2 的页面内容或 Harness 配置。

### 5.3 资源结构

主题颜色、画刷和图像引用放在独立 `ResourceDictionary` 中：

- 原主题：Windows 11 中性 Mica、系统强调色和标准 Fluent 控件样式。
- 鲸鱼娘主题：深海蓝、长春花蓝、冰青和极少量紫色强调色，支持 Light/Dark `ThemeDictionaries`。

角色大图只在 `WhaleGirl` 被选择时创建 `BitmapImage`/`ImageSource` 引用。切回 `Original` 后清除页面上的角色图引用，避免无意义的常驻解码内存。

## 6. WinUI 外壳

### 6.1 标题栏

使用 Windows App SDK 2.3.1 中的 `Microsoft.UI.Xaml.Controls.TitleBar` 替换现有手写标题栏网格：

- `IconSource`：LocalWhale 16/24 px 图标。
- `Title`：`LocalWhale`。
- `Subtitle`：紧凑显示连接状态和 Harness 版本，例如 `已连接 · Harness 0.1.0-rc.6`。
- `RightHeader`：连接状态视觉标记和“…”菜单按钮。
- 系统继续绘制最小化、最大化和关闭按钮，并由 `TitleBar` 为标题按钮和最小拖拽区分配空间。
- 保留 Mica；不使用自绘标题按钮或覆盖系统 DPI 命中区。

参考：

- <https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/title-bar>
- <https://learn.microsoft.com/en-us/windows/apps/develop/title-bar>

### 6.2 “…”菜单

菜单顺序固定为：

1. 外观主题（子菜单：原主题、鲸鱼娘）
2. 关闭时最小化到托盘（Toggle）
3. 分隔线
4. 检查 Harness 更新
5. 重启 Harness
6. 打开日志
7. 分隔线
8. 关于 LocalWhale

操作项使用语义清楚的 Segoe Fluent 图标；含义不够明确时保留文本，不为装饰而添加图标。

### 6.3 启动与恢复

WebView2 上方的启动状态层改成居中的 Fluent 卡片：

- 44–48 px LocalWhale 图标。
- 当前阶段标题与一行辅助说明。
- 原生 `ProgressRing`。
- 启动失败时在原位置切换为错误摘要、重试、打开日志三个操作。

原主题只显示产品图标与中性 Mica 卡片。鲸鱼娘主题在卡片右侧显示低对比、经过裁切的角色半身像，文字区保持独立不叠加。窗口宽度不足时隐藏角色图而不是压缩文本。

### 6.4 更新与关于

- 更新提示使用放置在右下角的 `InfoBar` 风格组件，包含版本号、简短说明和“更新 / 稍后 / 忽略”操作。
- 原主题和鲸鱼娘主题保持相同信息结构，只替换画刷和少量水波装饰。
- “关于”使用原生 `ContentDialog`。原主题显示产品徽记；鲸鱼娘主题可显示角色头像和人设署名说明。

## 7. 设置迁移与数据安全

v0.1.1 必须复用现有设置加载和原子写入机制：

- JSON 反序列化允许缺少 `VisualTheme`。
- 读取 v0.1.0 设置后只补默认值，不删除或重置 `CloseBehavior`、`IgnoredHarnessVersions`、`LastUpdateCheckUtc`。
- 保存继续采用临时文件写入后原子替换。
- 安装器覆盖安装不得删除 `%LOCALAPPDATA%\LocalWhale`。
- 主题切换不得读取、复制或写入 `~/.dsh`，也不得触碰其中的 API Key。
- 无效主题值记录一条脱敏警告，然后使用 `Original`，下一次正常保存时再规范化。

## 8. 资源与性能预算

- 应用图标及小尺寸 PNG 总体积应保持在合理的小体积范围内。
- 发布包中的角色主题图使用针对窗口显示尺寸优化后的派生图，不直接加载 2.3 MiB 人设母版。
- 主题插画最长边建议不超过 1200 px；保留透明度时使用优化 PNG，否则使用 WinUI 可稳定解码的压缩格式。
- 不使用循环动画；只保留 `ProgressRing` 和原生控件状态过渡。
- 角色主题启用后的外壳私有内存增量目标不超过 12 MiB。
- 继续满足既有空闲 CPU、启动时间和总工作集门槛。

## 9. 可访问性与响应式行为

- 连接状态同时提供文字，不只依赖彩色圆点。
- 所有菜单项、主题选择和恢复操作可使用键盘访问。
- 图标和装饰图提供合适的自动化名称或标记为装饰性。
- 高对比模式下停用角色背景与自定义低对比画刷，回退到系统资源。
- 100%、150%、200% DPI 下验证标题栏、菜单和标题按钮命中区。
- 窗口变窄时优先隐藏非必要的版本副标题和角色装饰，保留标题、状态和菜单。
- 尊重系统减少动画设置。

## 10. 版本与发行物

版本统一提升到 `0.1.1`：

- 程序集版本、文件版本、产品版本。
- Inno Setup `AppVersion` 与安装器文件名。
- About 对话框和标题栏显示。
- README 中的版本、功能说明、两种主题截图和升级说明。
- GitHub Release 标签及 Release Notes。

安装器继续允许用户选择安装路径，并以 per-user、`PrivilegesRequired=lowest` 模式安装。

## 11. 验收标准

### 11.1 图标

- Explorer、EXE 属性、窗口、任务栏、Alt+Tab、托盘、安装器和卸载项均显示 LocalWhale 图标。
- 16、20、24、32 px 下能辨认鲸尾水滴轮廓和 L 水波，不出现人物细节糊块。
- 浅色、深色任务栏上均有足够对比度。

### 11.2 主题与 UI

- 新安装和 v0.1.0 升级后均默认为原主题。
- 切换到鲸鱼娘主题后立即更新宿主外壳，Harness 页面不发生 DOM 或样式变化。
- 重启 LocalWhale 后保留用户主题选择。
- 启动、失败恢复、更新和关于界面在两种主题下均可读、可操作。
- 标题栏使用系统标题按钮，高 DPI、Snap、最大化和多显示器操作正常。

### 11.3 迁移与回归

- 使用包含 v0.1.0 字段的真实形态设置样本验证升级，不丢失已有字段。
- 覆盖安装后 `%LOCALAPPDATA%\LocalWhale` 与 `~/.dsh` 保留。
- 关闭行为、托盘、单实例、Harness 启停、更新与回滚行为不回归。
- Release x64 构建与安装包均成功生成。

## 12. 实施顺序建议

1. 增加设置枚举、兼容读取与迁移测试。

3. 接入 EXE、AppWindow、托盘和安装器图标。
4. 引入官方 `TitleBar` 并整理菜单。
5. 建立原主题与鲸鱼娘主题资源字典及切换服务。
6. 改造启动/恢复、更新和关于界面。
7. 更新版本、README、截图和安装器。
8. 执行迁移、UI、构建和安装验证。
