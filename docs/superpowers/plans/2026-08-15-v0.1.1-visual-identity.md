# LocalWhale v0.1.1 Visual Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship LocalWhale 0.1.1 with a simple, consistent Windows application icon, a more native Fluent WinUI shell, and an opt-in WhaleGirl theme while preserving every v0.1.0 setting and leaving the official Harness WebUI untouched.

**Architecture:** Keep persistent theme choice and tolerant JSON migration in `LocalWhale.Core`; keep resource-dictionary switching, WinUI controls, AppWindow icon wiring, and tray integration in `LocalWhale.App`. Generate brand assets reproducibly from one geometric definition and commit the outputs so normal builds need no image toolchain. Keep the approved character sheet in `design/`; publish only one optimized transparent portrait, loaded by the optional theme.

**Tech Stack:** .NET 10, C# 14, WinUI 3, Windows App SDK 2.3.1, WebView2, System.Text.Json source generation, xUnit v3, PowerShell, Python 3.11 + Pillow for maintainer-only image generation, Inno Setup 6.

## Global Constraints

- Support Windows 11 x64 only; keep `net10.0-windows10.0.22621.0`, unpackaged and self-contained.
- Keep Windows App SDK `2.3.1`; add no UI framework or runtime dependency.
- `VisualTheme.Original` is the default for new installs and v0.1.0 upgrades; `VisualTheme.WhaleGirl` is opt-in.
- Both themes follow Windows light/dark mode; high contrast hides decorative character art and uses system brushes.
- Never inject CSS or JavaScript into Harness WebView2 and never fork/restyle upstream UI.
- Preserve `%USERPROFILE%\.dsh`; never read, copy, migrate, or remove its credentials.
- Preserve `CloseBehavior`, ignored Harness versions, and last update-check time from v0.1.0 JSON.
- Use icon colors `#24366F`, `#BDEEFF`, and at most accent `#5F8FE6`; no face, text, fine shadow, or complex gradient.
- Keep the 2.3 MiB character sheet out of publish output; ship only the optimized theme portrait.
- Bump all LocalWhale product surfaces to `0.1.1`; leave Harness `0.1.0-rc.6`, Node `24.18.1`, and pnpm `11.7.0` unchanged.
- Never stage the older local-only `docs/superpowers/plans/2026-08-15-public-github-release.md`.

```csharp
[JsonConverter(typeof(VisualThemeJsonConverter))]
public enum VisualTheme { Original = 0, WhaleGirl = 1 }

public sealed class VisualThemeJsonConverter : JsonConverter<VisualTheme>
{
    public override bool HandleNull => true;

    public override VisualTheme Read(ref Utf8JsonReader reader, Type type, JsonSerializerOptions options)
    {
        if (reader.TokenType == JsonTokenType.Number && reader.TryGetInt32(out var number))
            return number == 1 ? VisualTheme.WhaleGirl : VisualTheme.Original;
        if (reader.TokenType == JsonTokenType.String &&
            Enum.TryParse<VisualTheme>(reader.GetString(), true, out var parsed) && Enum.IsDefined(parsed))
            return parsed;
        if (reader.TokenType is JsonTokenType.StartObject or JsonTokenType.StartArray)
            using (JsonDocument.ParseValue(ref reader)) { }
        return VisualTheme.Original;
    }

    public override void Write(Utf8JsonWriter writer, VisualTheme value, JsonSerializerOptions options) =>
        writer.WriteStringValue(value == VisualTheme.WhaleGirl ? "WhaleGirl" : "Original");
}
```

- [ ] **Step 4: Implement fixed-map theme switching**

```csharp
private static readonly IReadOnlyDictionary<VisualTheme, Uri> ThemeUris =
    new Dictionary<VisualTheme, Uri>
    {
        [VisualTheme.Original] = new("ms-appx:///Themes/OriginalTheme.xaml"),
        [VisualTheme.WhaleGirl] = new("ms-appx:///Themes/WhaleGirlTheme.xaml")
    };

public VisualTheme CurrentTheme { get; private set; } = VisualTheme.Original;
public event EventHandler<VisualTheme>? ThemeChanged;

private ResourceDictionary? _activeDictionary;

public ShellThemeService()
{
    var originalSource = ThemeUris[VisualTheme.Original];
    _activeDictionary = Application.Current.Resources.MergedDictionaries
        .FirstOrDefault(dictionary => dictionary.Source == originalSource)
        ?? throw new InvalidOperationException("Original shell theme was not loaded by App.xaml.");
}

public void Apply(VisualTheme theme)
{
    if (!ThemeUris.TryGetValue(theme, out var source))
    {
        theme = VisualTheme.Original;
        source = ThemeUris[theme];
    }

    if (CurrentTheme == theme && _activeDictionary?.Source == source) return;

    var dictionaries = Application.Current.Resources.MergedDictionaries;
    if (_activeDictionary is not null) dictionaries.Remove(_activeDictionary);
    _activeDictionary = new ResourceDictionary { Source = source };
    dictionaries.Add(_activeDictionary);
    CurrentTheme = theme;
    ThemeChanged?.Invoke(this, theme);
}
```

Do not accept arbitrary filesystem paths or URIs.
