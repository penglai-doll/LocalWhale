# LocalWhale mascot character sheet prompt

Create a polished ORIGINAL anime mascot character design sheet for a Windows desktop application named LocalWhale. This is a new design inspired only by the broad internet-culture idea of a friendly “AI whale girl”; do NOT copy any existing illustration, character, pose, face, costume, DeepSeek logo, or trademark.

Format: landscape professional character design sheet, approximately 16:9, pale cool-gray studio background with subtle blue drafting lines, clean spacious layout. Show one consistent young-adult character in: full-body front view, 3/4 view, back view; one large head-and-shoulders portrait suitable for simplifying into an app icon; three small facial expressions (calm smile, focused, playful wink); and close-up callouts for key accessories plus a compact color palette. No blocks of descriptive writing and no fake paragraphs; tiny simple labels may be omitted rather than garbled.

Character identity: elegant, friendly, clever, slightly mischievous; clearly an adult, non-sexualized. Long silvery-white hair with cool blue underside gradients, luminous deep-blue eyes, two subtle fin-shaped side locks, a small navy forehead ornament/soft eyepatch-like seal that can be lifted in the playful expression, and a small translucent whale-tail hair ornament. The silhouette must remain recognizable at small sizes: rounded face, asymmetric fringe, twin fin side-locks, whale-tail accent.

Costume: original refined blue-and-white layered marine dress combining a short sailor-inspired jacket with a modest knee-length skirt; opaque fabric, practical proportions, long detached sleeves or cuffs, navy piping, cyan luminous accents, pearl-like fasteners, low practical boots. Add a short translucent capelet whose hem resembles a whale tail and a small droplet pendant containing an abstract L-shaped wave mark unique to LocalWhale. No exposed midriff, no cleavage, no maid costume, no school uniform, no logos from existing companies.

Visual style: high-end Japanese game character concept art, crisp cel shading, precise line art, restrained gradients, coherent anatomy, professional production sheet, Microsoft Fluent-adjacent palette of midnight navy, periwinkle blue, cyan, ice white, and a tiny violet accent. Strong clean silhouette and readable accessory design. The large portrait should work as the source for a future Windows EXE/taskbar icon, with the face centered and no tiny clutter around it. Make every view consistent in hairstyle, colors, clothing, and accessories. No watermark, no signature, no unrelated characters.
